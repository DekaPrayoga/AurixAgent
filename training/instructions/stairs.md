# Stairs

## What to look for
- **Horizontal steps** — repeated flat surfaces going up or down
- **Step edges** — visible risers (vertical face) and treads (flat top)
- **Handrails** — metal or wooden rails alongside stairs
- **Repeating pattern** — parallel horizontal lines at regular intervals
- **Context** — building entrances, subway stations, pedestrian overpasses

## Common false positives (DO NOT select)
- Escalators (moving stairs with grooved surface, metal)
- Ramps (smooth slope, no steps)
- Shadows that create line patterns
- Venetian blinds or window patterns
- Parking garage barriers

## Edge cases
- Stairs at steep angle — still shows repeating horizontal pattern
- Short staircase (2-3 steps) — still count
- Spiral stairs — curved but still has steps
- Stairs partially obscured — count if step pattern is clear
