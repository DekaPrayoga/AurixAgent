# Motorcycles

## What to look for
- **Two wheels** visible (front and rear), connected by a frame
- **Handlebars** — curved or straight bar at the top front
- **Rider silhouette** — person sitting/leaning on the motorcycle
- **Engine/exhaust pipe** — metal cylinder below the frame
- **Headlight** — round or angular light at the front
- **Gas tank** — bulging shape between seat and handlebars

## Common false positives (DO NOT select)
- Bicycles (no engine, thinner frame, no gas tank)
- Cars viewed from side (side mirrors can look like handlebars)
- Scooters with 3 wheels
- Blurry shapes that only vaguely resemble motorcycles

## Edge cases
- Motorcycle partially cut off at edge — still count if 2+ features visible
- Motorcycle at distance — look for the distinctive 2-wheel silhouette
- Multiple motorcycles in one tile — select that tile
- Motorcycle with rider vs without — both count
