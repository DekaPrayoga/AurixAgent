# Podcast Transcription & Analysis

Find, transcribe, and analyze podcast episodes to extract insights and summaries.

## Tools

- `web_search` - Locate podcast episodes, show notes, and related transcripts
- `web_fetch` - Retrieve transcript text and episode metadata from web sources

## Instructions

- Search for available transcripts or show notes before attempting to summarize an episode
- Extract key topics and themes discussed, organizing them into a structured outline
- Summarize episodes concisely, capturing the main arguments, takeaways, and notable quotes
- Cross-reference episode content with `web_search` to verify claims or add external context
