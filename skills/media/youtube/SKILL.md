# YouTube Content Analysis

Extract, analyze, and summarize content from YouTube videos using transcripts and metadata.

## Tools

- `youtube_transcript` - Fetch and parse video transcripts and captions
- `web_search` - Look up related context, fact-check claims, and find supplementary sources

## Instructions

- Extract the full transcript before summarizing to ensure no key points are missed
- Summarize key points clearly, organizing them by topic or chronological flow as appropriate
- Identify specific claims made in the video and note which ones may need verification
- Use `web_search` to cross-reference facts and provide additional context where useful
