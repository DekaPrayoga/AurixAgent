# Stock Analysis Skill

Complete trading analysis pipeline inspired by TradingAgents.

## Agents
- Bull Researcher: Finds positive signals and opportunities
- Bear Researcher: Identifies risks and negative factors
- News Analyst: Processes market news and sentiment
- Technical Analyst: SMA, RSI, MACD, Bollinger Bands
- Risk Manager: Volatility, drawdown, Sharpe ratio

## Workflow
1. Data collection (yfinance)
2. Technical analysis (indicators)
3. Sentiment analysis (news)
4. Risk assessment (volatility metrics)
5. Final report with buy/sell/hold recommendation

## Tools
Use `trading` tool with actions: analyze, technical, sentiment, risk, report
