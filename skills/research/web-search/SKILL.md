# Web Search

Search the web and gather information from diverse sources efficiently.

## Tools

- `web_search` - Search the web for information
- `web_fetch` - Fetch and extract content from specific URLs
- `scraper` - Scrape structured data from websites

## Instructions

- Use multiple search queries with different keywords to get comprehensive results
- Prioritize source diversity including academic, news, and official documentation
- Fact-check important claims by verifying across at least 2-3 reliable sources
