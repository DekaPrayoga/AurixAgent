# Claim Verification

Verify claims through structured debate and fact-checking using multiple AI agents.

## Tools

- `ClaimExtractor` - Extract and classify claims
- `SupporterAgent` / `SkepticAgent` - Build and challenge arguments
- `JudgeAgent` - Evaluate evidence and issue verdicts

## Instructions

- Classify claims by type (factual, opinion, prediction) and verifiability
- Debate both sides thoroughly using supporter and skeptic agents
- Issue clear verdicts (true, false, misleading, unverified) with reasoning
