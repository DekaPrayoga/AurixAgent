# Quick Fact-Checking

Rapidly verify facts and claims using reliable sources.

## Tools

- `web_search` - Search for verification from multiple sources
- `web_fetch` - Fetch content from authoritative sources

## Instructions

- Check multiple reliable sources including fact-checking organizations and official sources
- Note consensus among sources and highlight any significant disagreements
- Flag uncertainty when sources conflict or evidence is insufficient
- Prioritize recent sources but note when historical context is relevant
