# Content Summarization

Summarize articles, videos, and other content while preserving key information.

## Tools

- `web_fetch` - Fetch and extract content from web pages
- `youtube_transcript` - Extract transcripts from YouTube videos

## Instructions

- Present key points first in order of importance or relevance
- Preserve nuance, caveats, and important context from the original
- Always cite the original source with URL and publication date
- Adjust summary length based on user needs (brief overview vs detailed summary)
