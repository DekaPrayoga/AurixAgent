# Red Team Skill

Offensive security operations for authorized testing.

## Capabilities
- Port scanning (nmap)
- Vulnerability scanning
- Banner grabbing
- Subdomain enumeration
- SSL/TLS analysis
- Technology fingerprinting
- Reconnaissance automation

## Rules
- ONLY test systems you have authorization for
- Document all findings
- Never exploit without explicit permission
- Generate pentest reports for documentation

## Tools
Use `cybersec` tool with team=red
