# Sprint Planning Skill

Agile project planning and task management.

## Capabilities
- Create project plans
- Decompose features into stories
- Sprint planning with capacity
- Roadmap generation
- Progress tracking

## Story Format
Each story has:
- ID (S1, S2, ...)
- Title
- Status (pending, in-progress, done)
- Tasks list
- Dependencies

## Tools
Use `planning` tool with actions: create, decompose, sprint, roadmap
