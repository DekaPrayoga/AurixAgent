# Calendar & Scheduling Management

Manage calendar events, detect conflicts, and handle scheduling logistics.

## Tools

- `terminal` - Execute calendar CLI commands for event creation, listing, and modification

## Instructions

- Always account for timezones when creating or comparing events to avoid scheduling errors
- Detect and flag conflicts between new and existing events before confirming changes
- Set reminders for upcoming events based on user preferences or event importance
- Confirm changes with the user before modifying or deleting existing calendar entries
