# Project Management

Plan, track, and manage projects from initiation through delivery.

## Tools

- `todo` - Track tasks, subtasks, and completion status
- `planning` - Create project plans, timelines, and resource allocations
- `generate_diagram` - Visualize project structures, timelines, and dependencies

## Instructions

- Define clear milestones with measurable deliverables and target dates for each project phase
- Map task dependencies explicitly to identify critical paths and potential bottlenecks early
- Track and report project status regularly, flagging risks and blockers as they arise
- Use visual diagrams to communicate project structure and timelines to stakeholders
