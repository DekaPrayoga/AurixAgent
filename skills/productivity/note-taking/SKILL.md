# Note Organization & Knowledge Management

Structure, organize, and maintain notes and knowledge bases for easy retrieval.

## Tools

- `memory` - Persist notes and knowledge entries for long-term retrieval
- `write_file` - Create and update structured note files on disk

## Instructions

- Use a structured format with clear headings, bullet points, and sections for every note
- Tag notes with descriptive labels to enable fast search and filtering across the knowledge base
- Link related notes together using references or cross-links to build a connected information web
- Review and consolidate notes periodically to merge duplicates and update stale information
