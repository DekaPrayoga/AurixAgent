# Visual Design & Diagrams

Create clean visual designs, diagrams, and structured layouts for technical and creative projects.

## Tools

- `generate_diagram` - Produce diagrams, flowcharts, and visual schematics
- `web_fetch` - Retrieve reference images, design assets, and style guides

## Instructions

- Keep layouts clean and uncluttered, using whitespace effectively to guide the eye
- Use a consistent color palette throughout all visuals to maintain visual coherence
- Ensure accessibility by checking color contrast ratios and providing alt text where applicable
- Prefer simple, readable diagram structures over visually complex ones
