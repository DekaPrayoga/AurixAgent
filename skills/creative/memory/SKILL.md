# Long-Term Memory & Knowledge Base

Store, organize, and retrieve information across sessions using persistent memory.

## Tools

- `memory` - Save, search, and manage long-term memory entries

## Instructions

- Tag all memory entries with clear, descriptive labels for fast and accurate retrieval later
- Link related memory items together to build a connected knowledge graph over time
- Perform periodic reviews of stored memories to prune outdated entries and consolidate related ones
- Use specific, searchable keywords when saving entries to avoid ambiguity on future lookups
