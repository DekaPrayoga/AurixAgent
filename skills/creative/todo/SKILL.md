# Task Management

Organize, track, and manage tasks and to-do lists effectively.

## Tools

- `todo` - Create, update, and manage task lists and subtasks

## Instructions

- Prioritize tasks by urgency and importance, surfacing high-impact items first
- Break large tasks into smaller, actionable subtasks that are easy to track and complete
- Set clear deadlines on tasks to maintain momentum and enable time-based planning
- Regularly review and update task status to keep lists accurate and actionable
