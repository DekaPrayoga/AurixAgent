# DeFi Protocol Analysis

Analyze decentralized finance protocols for risks and opportunities.

## Tools

- `evm_wallet` - Query blockchain data and smart contract interactions
- `web_search` - Search for protocol information and audits
- `web_fetch` - Fetch protocol documentation and analytics

## Instructions

- Check Total Value Locked (TVL) trends and protocol metrics
- Verify audit status from reputable firms and note any unaudited components
- Assess smart contract risks including upgradeability, admin controls, and known vulnerabilities
