# Budget and Expense Tracking

Create and manage budgets, track expenses, and identify savings opportunities.

## Tools

- `generate_excel` - Create budget spreadsheets and expense trackers
- `web_search` - Search for budgeting strategies and benchmarks

## Instructions

- Categorize expenses into fixed (rent, utilities) and variable (food, entertainment)
- Track spending trends over time to identify patterns and problem areas
- Suggest specific savings opportunities based on spending analysis
- Set realistic budget goals and create visual progress tracking
