# Cryptocurrency Analysis

Analyze cryptocurrency projects, wallets, and on-chain data.

## Tools

- `evm_wallet` - Query Ethereum and EVM-compatible blockchain wallets
- `solana_wallet` - Query Solana blockchain wallets
- `web_search` - Search for project information and market data

## Instructions

- Check on-chain data including transaction history, balances, and token holdings
- Verify contract addresses carefully to avoid scams and honeypots
- Note volatility and market conditions when discussing prices or projections
