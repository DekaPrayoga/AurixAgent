## Reddit launch post

Title:
I built an open-source terminal AI agent that can code, research, and execute real tasks

Body:
I have been working on AURIX, an open-source terminal AI workspace built for technical users.

The idea is simple: most AI tools can answer questions, but fewer can actually do useful work inside a real environment.

AURIX can:
- inspect repositories
- edit files
- run commands
- perform cited research
- generate PDFs and reports
- automate browser tasks
- run through Terminal, Discord, Telegram, and WhatsApp

I wanted something that feels closer to an AI command center than a normal chatbot.

Would love feedback on the product, README, positioning, and which use case feels most compelling.
